DN42Atlas

A polite directory and discovery project for public services on DN42.

Directory, not scanner

DN42Atlas records limited public service metadata for a directory. It is not a vulnerability scanner and does not perform exploit attempts, authentication attempts, or path brute forcing.

Complete exclusion

An approved complete exclusion means:

  • the hostname or prefix will not be probed in future scans;
  • it will not appear in published Atlas results;
  • exclusion updates re-filter the current Atlas artifacts without waiting for another crawl.

Use authenticated self-service for resources you can authorize through Auth42. If self-service cannot handle your request, including broader or wildcard exclusions, ownership/authentication problems, corrections, or other concerns, submit a manual request. Manual requests require review and do not immediately create an exclusion. If those options are unavailable, you can open a GitHub issue as a backup. GitHub issues are public; do not include sensitive information. See the opt-out documentation for details.

robots.txt

robots.txt controls page-content fetching. It does not prevent all service probing or listing. Request complete exclusion to prevent both probing and publication.
