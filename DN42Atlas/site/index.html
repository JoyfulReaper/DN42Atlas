DN42Atlas

A polite directory and discovery project for public services on DN42.

Private preview

DN42Atlas is currently in private preview.

Public service listings will not be published before October 16, 2026.

Operators can request complete exclusion during the preview period. Authenticated self-service and the manual request form are available now.

Directory, not scanner

DN42Atlas records limited public service metadata for a directory. It is not a vulnerability scanner and does not perform exploit attempts, authentication attempts, or path brute forcing.

Complete exclusion

An approved complete exclusion means:

  • the hostname or prefix will not be probed in future scans;
  • it will not appear in published Atlas results;
  • exclusion updates re-filter the current Atlas artifacts without waiting for another crawl.

Use authenticated self-service for resources you can authorize through Auth42. If self-service cannot handle your request, including broader or wildcard exclusions, ownership/authentication problems, corrections, or other concerns, submit a manual request. Manual requests require review and do not immediately create an exclusion. See the opt-out documentation for details.

robots.txt

robots.txt controls page-content fetching. It does not prevent all service probing or listing. Request complete exclusion to prevent both probing and publication.
