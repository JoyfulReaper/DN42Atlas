DN42Atlas

A directory of publicly reachable services on DN42.

Status

DN42Atlas is currently in private preview.

The crawler and report generator are being tested. Public service listings are not currently published.

About

DN42Atlas collects publicly available information about services registered in the DN42 network and generates a static directory.

The goal is to make discovering interesting DN42 services easier while respecting network operators.

Scan Policy

  • Only DN42 registered domains are considered.
  • robots.txt is respected where available.
  • Operators may request exclusion.
  • This is a directory, not a vulnerability scanner.

Opt Out

Before public indexing begins, operators can request exclusion.
