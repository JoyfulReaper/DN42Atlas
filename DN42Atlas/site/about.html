DN42Atlas

A polite directory and discovery project for public services on DN42.

What is this?

DN42Atlas discovers publicly reachable services advertised on the DN42 network and builds a browsable directory from the results. Crawl results are not being published yet.

The project is intended for network exploration and service discovery, not vulnerability scanning.

What does the scanner do?

DN42Atlas starts with names registered in the DN42 registry and performs limited service discovery.

For HTTP and HTTPS services, Atlas currently:

  • resolves registered .dn42 names;
  • probes a small curated set of common web-service ports;
  • requests /robots.txt before fetching page content;
  • fetches / only when robots rules allow it;
  • records basic public metadata such as HTTP status, title, content type, redirects, and links;
  • records referenced .dn42 hostnames;
  • does not recursively crawl discovered links;
  • does not automatically follow redirects;
  • limits response sizes and concurrency.

What DN42Atlas does not do

DN42Atlas is not intended to test the security of services.

  • No password guessing.
  • No authentication attempts.
  • No path brute forcing.
  • No vulnerability scanning.
  • No exploit attempts.
  • No recursive web crawling.
  • No intentional access to private content.

Scanner identification

HTTP requests from the crawler identify themselves using: 

DN42Atlas/0.2 (+https://dn42atlas.dn42/)

The scanner identity points to the Atlas home at dn42atlas.dn42.

robots.txt

DN42Atlas respects robots.txt when deciding whether it may fetch HTTP page content.

To prevent DN42Atlas from fetching your site's pages: 

User-agent: DN42Atlas
Disallow: /

A rule applying to all crawlers is also honored: 

User-agent: *
Disallow: /
Important:

A robots exclusion prevents page-content crawling. Atlas may still make the minimal connection required to discover that a public service exists and to retrieve its robots policy.

Complete opt-out

If you operate a DN42 host and do not want it included in DN42Atlas at all, you can request a complete exclusion.

Open an issue in the DN42Atlas repository and include the hostname or prefix you want excluded:

github.com/JoyfulReaper/DN42Atlas/issues

Complete exclusions are maintained separately from robots.txt and prevent Atlas probing and inclusion in its generated results.

Please only request exclusion for resources you operate.

Data collected

Atlas is interested in services, not users.

Scan snapshots may contain:

  • DN42 hostname;
  • resolved DN42 addresses;
  • protocol and port;
  • service reachability;
  • HTTP response metadata;
  • public page titles;
  • publicly exposed links;
  • publicly referenced DN42 hostnames;
  • timestamps showing when a service was observed.

DN42Atlas does not intentionally collect credentials, private application data, or user accounts.

Future protocols

Atlas may eventually perform similarly conservative discovery for other protocols commonly found on DN42, including:

  • FTP;
  • Gopher;
  • Gemini;
  • Finger;
  • QOTD.

Protocol discovery will remain limited to the minimum interaction necessary to identify a publicly exposed service.
